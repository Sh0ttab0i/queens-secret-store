## How to get the full working store live

The complete Bitcoin-enabled `index.html` is available for download from the conversation (file name: `queens-secret-bitcoin.html`).

### Recommended: Netlify (fastest)
1. Download the full `queens-secret-bitcoin.html` file
2. Rename it to `index.html`
3. Go to https://app.netlify.com/projects/queens-secret
4. Drag & drop the file on the Deploys page
5. Site goes live at https://queens-secret.netlify.app

### Alternative: GitHub Pages
1. Replace the current `index.html` in this repo with the full downloaded version
2. Settings → Pages → Source = `main` → Save
3. Live at https://sh0ttab0i.github.io/queens-secret-store/
